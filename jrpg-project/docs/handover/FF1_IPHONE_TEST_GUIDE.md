# Panduan Uji Manual iPhone — Batch FF1

1. Buka game di Safari iPhone (landscape dan portrait).
2. Mulai battle (encounter biasa atau `?debug=1` + tombol boss).
3. Verifikasi:
   - Musuh berada di kiri, party di kanan menghadap kiri.
   - Jendela bawah menampilkan nama musuh dan status HP/MP seluruh party aktif.
   - Saat giliran pemain, jendela perintah muncul di atas jendela musuh dengan 5 perintah yang sama (Serang, Skill, Item, Bertahan, Kabur).
   - Tap dan keyboard (jika ada) dapat memilih perintah dan target.
   - Tidak ada sprite yang keluar dari area latar atau tumpang tindih secara kasar.
4. Catat masalah visual, sentuhan, atau layout pada lebar layar berbeda.
