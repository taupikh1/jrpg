# Narrative Continuity Rules

1. Canon documents in docs/narrative/ override ad-hoc ideas.
2. CHANGELOG.md required for any retcon.
3. Character knowledge matrix gates dialogue facts.
4. Mysteries in MYSTERY_REGISTER must have planned resolutions.
5. Main chapters are sequential; no forward dependencies.
6. Stable content IDs only — never array indices as identity.
7. Engine gaps (e.g. limited choice persistence) must be documented, not faked.
8. No external copyrighted lore.
