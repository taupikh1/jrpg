# World Bible — Lumerra

## Identity
Lumerra is a vast, lived-in fantasy world where magic is the **Resonance** between life, place, and memory. Geography spans soft river valleys, crown-held plains, lantern cities, coastal tide reaches, verdant ruins, and underdeep holds.

## Cultural Attitudes to Resonance
| Culture | View |
|---------|------|
| Ashen Crown scholars | Measurable field; regulated study |
| Tidefolk | Sacred song of the living sea |
| Road couriers | Practical navigation aid / hazard |
| Ancient builders | Lattice to stabilize memory itself |
| Rural villages | Seasonal blessing; mistrust of “taking” |

## Design Principles
- Places feel inhabited before the plot arrives.
- Magic has social rules, not only combat rules.
- Memory loss is local and personal before it is apocalyptic.
