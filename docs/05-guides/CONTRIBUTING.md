# Contributing

- Baca TECHNICAL_ARCHITECTURE sebelum menambah modul; patuhi aturan lapisan.
- Satu fitur per batch; jangan memulai batch berikutnya tanpa instruksi eksplisit.
- Setiap klaim selesai harus punya bukti sesuai QUALITY_GATES.
- Jangan membuat file kosong atau stub; buat file saat ada isi.
- Jalankan `node tools/validate-project.mjs` sebelum commit.
- Semua aset dan teks harus orisinal.
