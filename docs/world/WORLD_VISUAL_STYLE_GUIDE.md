# World Visual Style Guide — Lumerra

## Global direction
- Readable 16×16 tile fantasy; soft storybook atmosphere without copying external IP.
- Integer-scaled Canvas; `imageSmoothingEnabled = false`.
- Environmental storytelling: faded signage, blank inscriptions (Stillness), gentle Resonance glow (cyan/soft blue).

## Scale
- Tile: 16×16 px logical.
- Character footprint ≈ 12×12–14 px.
- Zone maps: modest grids (e.g. 20×14 village) until production art expands.

| Region | Palette mood |

## Implemented vs planned
- **Implemented:** procedural/placeholder colored rects + demo tileset keys.
- **Planned:** final tilesets per region, weather overlays, time-of-day (not Batch 8.0).

## Placeholder policy
Placeholder art must not be described as final production artwork in player marketing copy.
