# Missing Asset Report (Milestone 0)

## Critical Gaps
- Dedicated, clearly licensed multi-direction walk/idle sheets for main party (Orin, Mira, Kael, Iven, Tavi).
- Organized overworld terrain tileset (grass, path, water, forest) outside of mixed nested packs.
- Battle stage / backdrop images.
- Consistent UI window/frame set matching one style.

## Non-Critical / Workarounds
- Many monster types can be mapped from monster.zip after license check.
- Dungeon interiors have strong candidate tiles (Sandstone + Pixel Dungeon).
- Item icons exist in IconsPropsMonsters.
- Procedural art can remain as fallback for any missing piece.

## Recommendation
Proceed to Milestone 1 only with a small, license-reviewed subset (one character stand-in, one NPC, one enemy, one tileset, one UI icon set) to prove pipeline before full migration.
