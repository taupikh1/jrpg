# Asset Import Guide

1. Place PNG under `assets/art-overhaul/`.
2. Add a definition in a content registry module (see `content/art/prototype-registry.js`).
3. Record source path from PixelSRPG-Forge and license status.
4. Measure frame size (do not guess).
5. Register animation states that actually exist.
6. Load via existing AssetManager when integrating into main scenes.
7. Never claim commercial clearance.
