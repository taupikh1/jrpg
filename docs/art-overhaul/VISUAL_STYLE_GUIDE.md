# Proposed Visual Style Guide (Milestone 0)

## Target
Cohesive 2D pixel-art JRPG look using verified PixelSRPG-Forge assets where possible, falling back to existing procedural palette art.

## Rules
- Single integer pixel scale (recommend 2x or 3x logical).
- No stretching of small sprites.
- Consistent character proportions (aim for similar frame height across party).
- Tile size locked per zone (16 or 32 px — decide after measuring selected tileset).
- Shared shadow/outline treatment.
- UI icons same pixel density as world.
- Battle enemies visually distinct; bosses larger but not distorted.
- Palette: prefer assets that sit near existing earth/green/stone tones; document any deliberate shift.

## What We Will Not Do
- Convert to tactical grid SRPG.
- Add BGM.
- Change story, IDs, or gameplay systems for art convenience.
- Ship MapleStory assets without explicit owner approval and rights proof.
